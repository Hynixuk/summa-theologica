# Metaphysics Text & Audio Upgrade Plan

## Objective
Replace Books 3-14 of the McMahon 1857 translation (which contains OCR artifacts) with the W.D. Ross 1908 translation (cleaner, more scholarly), while keeping Books 1-2 from LibriVox's McMahon narration for continuity.

## Translation Choice: W.D. Ross 1908

### Why Ross over McMahon:
- **Public Domain**: Published 1908 (pre-1928 US copyright), fully public domain
- **Cleaner Text**: Minimal OCR artifacts compared to current McMahon scan
- **Scholarly Standard**: W.D. Ross was Oxford's foremost Aristotle scholar; this translation is the academic standard
- **Same Schema**: Already 14 books, Bekker chapter numbering matches your existing structure

### Current McMahon Issues:
Sample from current Book III Chapter 1:
```
"Dmibt-its advancement of the science under in niationto yestigation..."
"drfferent", "suQects", "acquitdtion" — widespread OCR corruption
```

## Implementation Steps

### Phase 1: Text Acquisition & Conversion (MANUAL/SEMI-AUTOMATED)

1. **Download Ross translation**
   - Visit: https://archive.org/details/metaphysics-aristotle-w.d.ross
   - Download the "Full text" (.txt) file or EPUB
   - Save to: `data/text/ross-raw.txt` (temporary)

2. **Parse into metaphysics.json structure**
   - Schema must match current format:
   ```json
   [
     {
       "book": 1,
       "bookTitle": "Book I (Α, \"the Greater Alpha\")",
       "chapter": 1,
       "paragraphs": [
         { "text": "..." },
         { "text": "..." }
       ]
     },
     ...
   ]
   ```

3. **Merge books 1-2 with books 3-14**
   - Keep Books 1-2 from current McMahon (for LibriVox audio continuity)
   - Replace Books 3-14 with Ross translation
   - Result: `data/text/metaphysics_merged.json`

4. **Clean OCR artifacts**
   - Run existing `clean-metaphysics-ocr.cjs` or similar
   - Fix obvious scanning errors
   - Preserve original Ross wording (minimal intervention)

### Phase 2: Audio Generation (AUTOMATED)

1. **Generate TTS for Books 3-14**
   - Use: `generate-metaphysics-tts.cjs` (to be created)
   - Voice: `en-GB-RyanNeural` (matches SCG Books 3-4)
   - Format: MP3, 48kbit mono (consistent with existing audio)
   - Output: `audio/metaphysics/` (tracks 07–32, appending to existing 01-06)

2. **Update manifests**
   - Update: `audio/metaphysics/manifest.json`
   - Add new tracks with proper duration metadata

### Phase 3: App Integration

1. **Rebuild data file**
   - Run: `node scripts/build-data-metaphysics.cjs`
   - This regenerates: `app/data-metaphysics.js`
   - Connects text to audio tracks via chapter numbers

2. **Test**
   - Verify Books 1-2 still play with LibriVox audio
   - Verify Books 3-14 play with new TTS audio
   - Spot-check text quality in UI

## Estimated Effort

- **Text preparation**: 2-4 hours (manual parsing + cleanup)
- **TTS generation**: ~8-12 hours (depends on text length; ~50-100 chars/sec synthesis)
- **Testing & iteration**: 1-2 hours
